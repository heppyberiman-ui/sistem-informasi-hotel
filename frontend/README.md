# Hotel Perhotelan Frontend

Website frontend Next.js untuk manajemen hotel yang terintegrasi dengan API lokal.

## Fitur

- Dashboard / Home modern
- Login user / admin
- Daftar kamar (GET /kamar)
- Detail kamar ketika diklik
- Tambah kamar (POST /kamar)
- Edit kamar (PUT /kamar/:id)
- Hapus kamar (DELETE /kamar/:id)
- Booking hotel (POST /booking)
- Daftar booking (GET /booking)

## Setup

1. Buka terminal di `d:\web perhotelan\frontend`
2. Jalankan `npm install`
3. Pastikan backend API berjalan di `http://localhost:3000`
4. Jalankan frontend dengan `npm run dev`
5. Buka browser di `http://localhost:3002`

# Sistem Informasi Hotel

Website Sistem Informasi Hotel berbasis Next.js dan Node.js yang menyediakan fitur manajemen kamar, booking hotel, dan login multi-role.

## Fitur

* Login Admin dan User
* Manajemen Kamar (CRUD)
* Booking Kamar
* Daftar Booking
* Role Admin dan User
* Tampilan Modern Responsive
* Galeri Hotel dan Kamar

## Teknologi

### Frontend

* Next.js
* React.js
* Bootstrap

### Backend

* Node.js
* Express.js
* MySQL
